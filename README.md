# Фреймворк для автоматизации расчётов лабораторных работ по физике

Курсовой проект по дисциплине «Программирование».

## Автор

Дворников М. С., группа ПИ-54.

## Описание

Консольный фреймворк для описания и расчёта лабораторных работ по физике.
Позволяет создавать таблицы с вычисляемыми столбцами, использовать формулы,
сохранять состояние работы.

## Сборка

g++ main.cpp *.cpp -o app
./app
