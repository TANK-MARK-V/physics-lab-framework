# Фреймворк для автоматизации расчётов лабораторных работ по физике

Курсовой проект по дисциплине «Программирование».

## Автор

Дворников М. С., группа ПИ-54.

## Описание

Консольный фреймворк для описания и расчёта лабораторных работ по физике.
Позволяет создавать таблицы с вычисляемыми столбцами, использовать формулы,
сохранять состояние работы.

Проект демонстрирует **композицию** и **агрегацию** между классами:

- **Композиция:** `Table` состоит из `Column` (часть не существует без целого).
- **Агрегация:** `Column` использует `Formula`, созданную снаружи.

## Связи между классами

| Связь | Тип | Описание |
|---|---|---|
| **Table → Column** | Композиция | Таблица владеет столбцами. Удаление таблицы удаляет столбцы |
| **Column → Formula** | Агрегация | Столбец использует формулу, созданную снаружи |
